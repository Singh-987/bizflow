# Rentello — Rental & Property Management System

Rentello is a rental and property management web application designed to help landlords manage properties, units, tenant leases, electricity billing, and rental finances in one place.

## Live Demo

[View the live application](https://rentello-omega.vercel.app/)

## Features

* **Property & Unit Management:** Add properties and manage individual units, rental amounts, and occupancy status.
* **Tenant & Lease Tracking:** Manage tenants and track active, upcoming, and ended leases.
* **Electricity Meter Billing:** Calculate electricity consumption and billing amounts using meter readings.
* **Financial Overview:** Track rent collected, pending balances, expenses, and overall rental finances.
* **Payment History:** View and manage rental payment records.
* **Activity & Notifications:** Stay informed about important rental and property activities.
* **Dark Mode:** Switch between light and dark themes.
