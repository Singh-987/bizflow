# Rentello — Rental & Property Management System

Rentello is a complete rental management web application built to help landlords manage properties, units, tenant leases, and utility billing in one place.

## Live Demo
Check out the live application: [rentello-omega.vercel.app](https://rentello-omega.vercel.app/)

## Features
- **Property & Unit Management:** Add properties and manage units with rent and occupancy status.
- **Tenant & Lease Tracking:** Track active, upcoming, and ended leases.
- **Electricity Meter Billing:** Calculates units used and costs based on meter readings.
- **Financial Overview:** Real-time ledger showing collected rent, pending balances, and total revenue.
- **Dark Mode Support:** Clean light and dark theme.

## Tech Stack
- Next.js 15 (React)
- TypeScript
- Tailwind CSS
- PostgreSQL & Prisma
- Better Auth
